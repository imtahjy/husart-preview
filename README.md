# 胡氏藝術 About — Editorial Motion

以「胡氏能為使用者帶來什麼價值」為核心，重新整理的精簡 About 互動原型。

## 預覽

直接開啟 `index.html`，或在此資料夾執行：

```bash
npm start
```

然後前往 `http://localhost:4173`。

## 互動

- 滾動閱讀進度與導覽自動收合
- Figma 版型黑底開場與置中專案小卡
- 小卡進站後自動輪播並自動放大至滿版
- 第一卡可點擊完整重播原始動畫時間軸
- 成果數字遞增動畫
- 滿版後浮現價值宣言
- 四項使用者問題與胡氏解法
- 實績數字遞增動畫
- 執行長資訊
- 可選擇的重要記事時間軸
- 合作夥伴類型
- 聯絡行動區塊
- 響應式手機選單
- `prefers-reduced-motion` 動態減量支援
